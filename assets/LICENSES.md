# Asset licenses

All visuals in this folder are programmatic geometry (PIL / hand-written SVG) — no AI-generated imagery, no third-party stock, no icon packs. Two open fonts are used for the type; both are commercially usable.

| Asset | License | Source | Local copy |
|---|---|---|---|
| Space Grotesk (variable, wght 300–700) | SIL Open Font License 1.1 | [google/fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) — upstream author Florian Karsten | `fonts/SpaceGrotesk.ttf`, `fonts/SpaceGrotesk-OFL.txt` |
| JetBrains Mono (variable, wght 100–800) | SIL Open Font License 1.1 | [google/fonts](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono) — upstream author JetBrains | `fonts/JetBrainsMono.ttf`, `fonts/JetBrainsMono-OFL.txt` |

The OFL permits commercial use, embedding, and modification; it only restricts selling the font files by themselves under a different license. Full text in each `*-OFL.txt`.

Fetched 2026-08-07 directly from the `google/fonts` repository (the canonical mirror both projects publish their releases through).

## Provenance

`hero-*.png` and `social-preview-*.png` were generated from a Python/Pillow script (four-segment ring diagram + the two fonts above, no other inputs), reviewed as two candidate directions in a sensory gate, and this pair was the one approved.
